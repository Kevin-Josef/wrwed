MapArtAssist – Auction Command Fix

Änderung:
- Der Verkaufsbefehl wird jetzt exakt als `ah sell <preis>` gesendet.
- Die Mod hängt keine Mengenangabe mehr an den Befehl an.
- Wenn die gefundene Angebotsmenge der eingestellten Menge entspricht, wird der gefundene Gesamtpreis unverändert verwendet.
- Vor dem automatischen Verkauf wird geprüft, ob ein gültiger gefundener Preis vorliegt.

Hinweis:
Dies ist das Quellprojekt als ZIP, keine fertige JAR. Die Änderung wurde hier nicht in Minecraft kompiliert oder auf dem Server getestet.
Wenn der Server für /ah sell eine andere Syntax verlangt, ist dessen Fehlermeldung im Chat entscheidend.
