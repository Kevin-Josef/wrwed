Version 1.11.0 (nicht kompiliert/getestet)

Spawner-Schutz
- Neu: nach dem Abbau (bzw. wenn nichts abzubauen war) wird ein frei einstellbarer Befehl/Text gesendet,
  Standard "/spawn". Beginnt er mit "/", wird er als Befehl gesendet, sonst als Chatnachricht.
- Standard ist jetzt: Befehl senden und ONLINE BLEIBEN. Danach schaltet sich der Schutz aus
  (Taste L = wieder an), damit er nicht sofort erneut ausloest.
- Optional "Danach Server verlassen" mit einstellbarer Wartezeit (1-15 s), damit der Teleport ankommt.
- Ist "Befehl ausfuehren" aus (oder der Befehl leer), wird wie bisher immer verlassen.

Menue
- Seitenleiste in Gruppen:  Makros (Auktions-Makro, HT1 Combat Lock, Spawner-Schutz),
  Kosmetik (Capes, Cape Creator), Taschenrechner, Litematica (Map Art).
- "Aussehen" ist aus der Navigation raus. Zahnrad oben rechts = Einstellungen:
  Akzent-/Hintergrundfarbe (Farbwaehler, Hex, Voreinstellungen), Menue-Titel,
  Hintergrund-Deckkraft, Hex-Animation an/aus, Uebergangs-Animationen an/aus, Alles zuruecksetzen.
- Textfelder werden jetzt ueber den Karten gezeichnet.

Taschenrechner
- Alle Sprueche/Kommentare entfernt (Ergebnisse bleiben unveraendert "falsch").
