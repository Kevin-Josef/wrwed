MapArtAssist – Auktionsbefehl und Mengenwahl

- Verkaufsbefehl: `ah sell <Preis> <Menge>`; die konfigurierte Menge wird mitgesendet.
- Die Menge kann im Makro-Menü durch Anklicken des Mengenfelds als Zahl eingegeben werden.
- Mit Enter bestätigen, Backspace korrigiert, Escape bricht die Eingabe ab.
- Eingaben werden auf 1 bis 64 begrenzt; bei Items mit kleinerem Stacklimit wird die Verkaufsmenge automatisch auf das Item-Maximum begrenzt.
- Preisberechnung skaliert den gefundenen Stückpreis auf die tatsächlich gesendete Menge, sofern nicht die exakt gefundene Gesamtmenge verwendet wird.

Dies ist ein Quellprojekt-ZIP, keine fertige JAR. Nicht in Minecraft kompiliert oder auf dem Server getestet.
