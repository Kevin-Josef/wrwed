MapArtAssist - Stack Only / Send Fix

- Makro bleibt auf volle Stacks begrenzt (Itemstack-Maximum, z. B. 64 TNT).
- Die Preissuche liest das billigste Angebot fuer exakt einen vollen Stack.
- Der Verkaufsbefehl ist /ah sell <gefundener Gesamtpreis> <Stacklimit>, z. B. /ah sell 249999 64.
- Der Testlauf wird deaktiviert, damit der Befehl tatsaechlich gesendet wird. Auch ein vorhandener gespeicherter Testlauf-Wert wird beim Laden deaktiviert.

WICHTIG: Quellprojekt-ZIP, keine fertige JAR. Nicht kompiliert oder im Spiel getestet. Der Verkauf sendet echte Befehle an den Server.
